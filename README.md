# Script-Jarvis
## 🚀 Ejecución

Copia y pega el siguiente comando en tu executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/marblack-o/Script-Jarvis/main/loader-allinone.lua"))()
```

> ⚠️ **Nota:** Asegúrate de que tu executor soporte `HttpGet` y `loadstring`. Se recomienda tener una clave API de Groq configurada para las funciones de IA.
